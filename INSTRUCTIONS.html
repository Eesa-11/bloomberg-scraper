Install Prerequisites

You need three things installed on your computer: Git, Docker Desktop, and a terminal. Follow the links for your OS.

  • Git: git-scm.com/downloads → install for your OS, keep all defaults
  • Docker Desktop: docker.com/products/docker-desktop → install and open it (must be running in background)

After installing, open a terminal (Command Prompt / PowerShell on Windows, Terminal on Mac/Linux) and verify:

git --version
docker --version

Both should print version numbers. If they do, you're ready.

3
Create GitHub Repository & Push Code

3a. Create a new repo on GitHub:

  1. Go to github.com/new
  2. Repository name: bloomberg-scraper
  3. Set to Public
  4. Do NOT check "Add a README file"
  5. Click Create repository

3b. Open a terminal, navigate to your folder and push:

# Navigate into your project folder (adjust path as needed)
cd ~/Desktop/bloomberg-scraper

# Initialize git
git init

# Add all files
git add .

# Commit
git commit -m "Add Bloomberg scraper with Selenium and Docker"

# Connect to GitHub (replace Eesa11 if needed)
git remote add origin https://github.com/Eesa11/bloomberg-scraper.git

# Push
git branch -M main
git push -u origin main

GitHub will ask for your username (Eesa11) and a password. Use a Personal Access Token as your password — not your GitHub login password:

  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Click "Generate new token (classic)"
  3. Check repo scope → Generate → Copy the token
  4. Paste it as your password in the terminal prompt
✓ After this, go to github.com/Eesa11/bloomberg-scraper — you should see your 4 files.
4
Build the Docker Image

Make sure Docker Desktop is open and running. Then in your terminal (inside the bloomberg-scraper folder):

# Build the image — this takes 5-10 minutes the first time
docker build -t orakzaieesa11/bloomberg-scraper:latest .

You'll see a lot of output. Wait until you see something like Successfully built ... or writing image ... done.

⚠ If you get an error about Chrome/ChromeDriver, make sure Docker Desktop is actually running (look for the whale icon in your taskbar/menu bar).
5
Push Image to Docker Hub

5a. Login to Docker Hub from terminal:

docker login

Enter your Docker Hub username (orakzaieesa11) and password.

5b. Push the image:

docker push orakzaieesa11/bloomberg-scraper:latest

This uploads your image to Docker Hub. Takes a few minutes depending on your internet speed.

✓ After this, go to hub.docker.com/u/orakzaieesa11 — you should see the bloomberg-scraper repository.
6
Test the Running Container

Run the container locally to make sure everything works:

docker run -p 7000:7000 orakzaieesa11/bloomberg-scraper:latest

Wait for it to say something like Running on http://0.0.0.0:7000. Then open a new terminal tab and test:

# Basic health check
curl http://localhost:7000/

# Test with a keyword
curl "http://localhost:7000/get?keyword=bitcoin"

Or just open this URL in your browser:

http://localhost:7000/get?keyword=bitcoin

You should get a JSON response like:

{
  "registration": "FA23-BAI-031",
  "newssource": "Bloomberg",
  "keyword": "bitcoin",
  "url": "https://www.bloomberg.com/news/articles/...",
  "summary": "..."
}
✓ If you see JSON with your registration number, everything is working!

Press Ctrl+C in the first terminal to stop the container.
